Works right here

Paste a link. Get a PDF.

Every picture a page publishes comes back as one file, bound in order. Our server does the fetching, so there is nothing to install and nothing to set up — this works on a phone that has never had a computer near it.

What you get

Every picture bound into a single document, in the order the page used.

Pictures are handled here because they need no merging and no transcoding. Video and audio are handled by the app on your own machine, which is also where they run fastest and stay entirely off anyone else's server.

—

Why it runs on your machine

The file is never somewhere else first.

Most download sites work by fetching the file onto their server, then handing you a copy. That server sees the link, the file, and you. Steading removes the middle step by removing the middle party.

01

Nothing is uploaded

The file is written straight to your disk by a program running on your own computer. There is no moment when a stranger's server is holding it, because no stranger's server is involved.

02

No account, no queue

Nothing to sign into and nobody ahead of you. There is no rate limit to hit and no plan to upgrade, because there is no service on the other end deciding how much you get.

03

It keeps working

What you saved is an ordinary file in an ordinary folder. It will still open when this page is gone, when this project is abandoned, and when whoever posted it has deleted the original.

Install

One command, then it is yours.

Steading needs Node, yt-dlp and ffmpeg. The setup script installs whatever is missing and adds nothing to your PATH. It runs only while you have it running.

Windows

PowerShell, run once.

scripts\setup-windows.ps1

macOS and Linux

Homebrew, apt, dnf or pacman — detected for you.

bash scripts/setup-unix.sh

Android

Inside Termux. No root, no laptop needed.

bash scripts/setup-termux.sh

No computer at all

Someone runs it once and shares the link; your phone just opens it.

npm run share
