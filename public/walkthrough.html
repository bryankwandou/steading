It is an ordinary file in an ordinary folder now.

  1. Paste a link

    Anything from the 1,752 sites yt-dlp knows. On a phone you can share straight to Steading from the app you are already in.

  2. It looks, before it fetches

    The link is read to find out what is actually there — how long, what heights exist, whether there is a video track at all. No bytes are downloaded yet.

  3. Choose the kind

    Video, audio or photo. Anything the post cannot provide is disabled rather than left to fail when pressed.

  4. Choose the shape

    Twelve formats. For photos a five-step slider trades size against fidelity — the four pages of the Wikipedia article on barns come back as 1.45 MB at Original and 333 KB at Small.

  5. It writes to your disk

    The file is produced on your machine from the start. There is no moment when a stranger's server is holding it.

  6. It is yours

    An ordinary file in an ordinary folder. It still opens when this page is gone and when whoever posted it has deleted the original.
